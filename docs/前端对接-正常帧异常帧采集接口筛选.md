# 正常帧、异常帧采集接口筛选前端对接

任务编号仅用于遥测及FEP文件的写入归属，所有实时、历史查询及参数勾选不按任务隔离。完整规则见[全局配置与任务归属](前端对接-全局配置与任务归属.md)。

正常帧和异常帧页面共用全局采集接口下拉框，支持按接口名称模糊搜索。下拉框使用单选，移除「全部采集接口」。

## 加载和搜索采集接口

调用管理服务 `GET /processing/collect-interfaces`，沿用现有 HTTP 鉴权。

| 查询参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `interfaceName` | 字符串 | 否 | 按采集接口名称做包含匹配。参数省略、为空或只有空白时，返回全部未删除的接口。 |

首次加载或清空搜索词时不传查询参数。输入关键词后传 `interfaceName`，由 HTTP 请求封装进行 URL 编码。

```http
GET /processing/collect-interfaces
GET /processing/collect-interfaces?interfaceName=UDP
```

响应示例

```json
{
  "code": 200,
  "message": "操作成功",
  "data": [
    { "interfaceId": 11, "interfaceName": "UDP 遥测接口 A" },
    { "interfaceId": 12, "interfaceName": "UDP 遥测接口 B" }
  ]
}
```

- 用 `data[].interfaceName` 显示选项名称，用 `data[].interfaceId` 作为选项值。
- 选项包含已启用和已停用的未删除接口。没有匹配项时返回 `data: []`。

## 选中接口后加载帧列表

**实时查看**使用管理服务的 `/ws/telemetry`。页面进入并选中接口后建立连接，连接打开后发送订阅 JSON。正常帧使用 `stream: "normal"`，异常帧使用 `stream: "abnormal"`。收到完整缓存快照后初始化列表，随后应用增量。

```json
{
  "accessToken": "登录令牌",
  "interfaceId": 11,
  "stream": "normal"
}
```

**历史查询**只需传选中的 `interfaceId`，不按任务过滤。

```http
GET /processing/realtime/telemetry?interfaceId=11
GET /processing/realtime/invalid?interfaceId=11
```

两条历史接口默认查询最近 15 分钟。需要指定范围时可传 `startTime`、`endTime`，格式为 `yyyy-MM-ddTHH:mm:ss`，可带毫秒。`data` 直接返回按帧时间倒序排列的数组，最多 100 条，无数据时返回 `[]`。请求无需传分页参数。

## 页面切换

1. 未选择采集接口时显示「请选择采集接口」。选中后再订阅实时帧或查询历史帧。
2. 切换采集接口时关闭旧连接并清空旧帧列表，再订阅新接口。
3. 任务变化不改变查询范围，不需要清空帧列表、已选接口或重新建立订阅。
4. 离开页面时关闭当前连接。
