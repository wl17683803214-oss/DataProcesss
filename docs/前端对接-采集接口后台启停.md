# 采集接口后台启停：前端变更说明

采集接口启用、禁用改为：保存设置成功后返回，实际启动和停止由后台同步执行。

## 请求与响应

继续调用 `POST /collection/interfaces/enabled`，字段及响应结构不变：

```json
{
  "id": 15,
  "enabled": 1
}
```

`enabled=1`启用，`enabled=0`禁用。成功响应仍为：

```json
{
  "code": 200,
  "message": "操作成功"
}
```

## 前端需要调整的交互

- 请求成功后即可结束按钮加载状态，并按现有方式刷新列表。
- 成功提示使用“启用设置已保存”或“禁用设置已保存”。返回成功代表配置已保存，不代表监听已经启动或停止完成。
- 当前列表中的“在线、离线”仍依据启用开关展示，不作为后台运行结果。
- 同步失败的结果从现有运行日志、采集告警页面查看，不增加轮询接口或响应字段。
- 连续启停按最后保存的设置为准，不需要等待上一轮后台同步结束。
- 新建、修改和删除采集配置也采用后台同步；保存成功后的原有关闭弹窗、刷新列表逻辑继续使用。

参数错误、监听配置冲突等保存阶段的错误仍按原有错误提示处理，不能在请求失败时显示“设置已保存”。
