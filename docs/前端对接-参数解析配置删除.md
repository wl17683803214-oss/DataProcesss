# 参数解析配置删除接口

本次新增删除接口，按设备卫星主键删除对应的整套参数解析配置。

## 接口

`POST /processing/rules/delete?deviceSatelliteId=12`

沿用现有登录鉴权。参数放在查询字符串中，无需请求体。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| deviceSatelliteId | 整数（int64） | 是 | 当前卫星或设备节点的主键，必须大于0；不是参数主键或系统主键 |

无需传 taskId、type，由后端根据设备卫星记录确定。

成功响应沿用统一结构：

```json
{"code":200,"message":"操作成功"}
```

删除范围：该设备或卫星目录、全部所属系统、全部参数解析配置，以及关联的组件数据项和失效勾选记录。整个操作处于同一事务，失败回滚。

记录不存在、已删除、编号不合法或仍被有效的本地PDXP协议配置引用时返回失败，前端展示后端中文 message。被引用时提示协议名称及设备或卫星名称，需要先调整对应协议关联。该接口不删除历史遥测数据。

## 页面接入建议

建议将删除入口放在“参数解析配置”页对应的卫星、设备节点旁边，不放在单条参数行旁边。

1. 点击删除后提示：“确认删除【名称】及其全部系统和参数解析配置吗？”
2. 用户确认后，提交当前节点的 deviceSatelliteId；请求期间禁用重复操作。
3. 成功后刷新卫星设备列表、系统树和参数列表；如果删除的是当前选中节点，清空原选择并重新选择有效节点。
4. 删除失败保留当前页面数据并显示后端提示。

## 文件夹默认展开状态

参数解析配置页首次进入时，卫星、设备和各级系统文件夹全部默认收起，不自动展开首个节点或全部节点；由用户点击后展开。删除成功重新加载目录时，也不要自动展开全部文件夹。
